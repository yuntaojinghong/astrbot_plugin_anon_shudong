# 匿名倾诉转述插件 (astrbot_plugin_anon_relay)

一个 [AstrBot](https://github.com/AstrBotDevs/AstrBot)（v4，Star API）插件：
用户私聊机器人，**只有发送「开启匿名模式」才会建立会话**；之后用户的倾诉内容会被机器人
以匿名的身份**转述**到指定的群聊 —— 由机器人重新拼装成一条新消息发出（`匿名昵称 + 内容`），
**不是转发聊天记录**，群成员看不到任何真实身份信息。

## 特性

- ⚡ 私聊自动匿名：白名单外的人私聊机器人**直接自动进入匿名模式**（无需关键词），内容自动匿名转述
- 💬 白名单自由聊天：白名单内的人可正常私聊（LLM 回复），需要匿名时发送「开启匿名模式」即可
- 🔇 关闭自动匿名后：未开启匿名模式的私聊保持沉默（拦截私聊并阻止默认 LLM 回复）
- 🗂️ 群聊模式：可在群内直接开启匿名模式；A 群的人倾诉只转述到 A 群，也可统一转述到多个群
- 🎲 随机匿名昵称：新用户从昵称池随机抽取（默认水果昵称，如【番茄】），同一用户固定不变
- 🧩 转述格式模板自由配置：默认 `【{name}】：{content}`，支持 `{name}` `{content}` `{time}` 占位符
- 🔄 消息转述：机器人以新消息形式发到群聊，不转发原消息记录
- 🖼️ 支持文字与图片转述，长文自动分段（每段套用格式模板）
- 🛡️ 管理机制：管理员可「禁言」某匿名身份一段时间，或「永久禁用」其匿名模式使用权限
- 🧼 脏话自动和谐：转述内容命中和谐词库自动替换为 `**`（词库可自定义）
- 📄 词库 txt 上传：和谐词库 / 审查词库 / 昵称池 可直接上传 txt 文件批量导入——既可在**插件设置页**上传，也可**聊天中直接发文件**给机器人（仅管理员），支持「重置词库」一键恢复面板配置
- ⏱️ 可选会话空闲超时；会话状态持久化在插件 KV 存储中，重启不丢
- 🛠️ 专属插件设置面板：全部行为可在 WebUI 插件配置面板中调整（`_conf_schema.json` 自动生成表单）
- 📡 多平台：QQ / Telegram / 微信等均可（通过 AstrBot 统一消息通道发送）

## 安装

**方式一：下载 zip 上传安装（推荐，最简单）**

1. 下载安装包：https://github.com/yuntaojinghong/astrbot_plugin_anon_relay/releases/latest/download/astrbot_plugin_anon_relay.zip
   （zip 文件名必须保持为 `astrbot_plugin_anon_relay.zip`，AstrBot 以 zip 文件名作为插件目录名）
2. WebUI → 插件管理 → 安装插件 → 上传该 zip
3. 在插件管理中**重载插件**
4. 进入该插件的**配置面板**，填写「目标群号」，保存后再次重载插件生效

**方式二：手动复制文件夹**

1. 将 `astrbot_plugin_anon_relay` 整个文件夹复制到 AstrBot 的插件目录：
   - 桌面版：`C:\Users\<用户名>\.astrbot\data\plugins\`
   - 服务器版（源码/systemd）：`<AstrBot根目录>/data/plugins/`
   - Docker 版：容器内 `/AstrBot/data/plugins/`（或通过挂载卷放入宿主机对应目录）
2. 在 WebUI「插件管理」中**重载插件**。
3. 进入该插件的**配置面板**，填写「目标群号」，保存后再次重载插件生效。

**方式三：从 GitHub 仓库安装**

WebUI → 插件管理 → 安装插件 → 从 GitHub 仓库安装，填入
`https://github.com/yuntaojinghong/astrbot_plugin_anon_relay`（要求服务器能访问 GitHub）。

## 配置面板

WebUI → 插件管理 → 找到「匿名倾诉转述」→ 点击配置按钮。面板表单由插件目录下的
`_conf_schema.json` 自动生成，所有字段均可修改：

| 配置键 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关，关闭后插件完全不响应 |
| `start_keywords` | `开启匿名模式` | 开启会话的关键词（私聊/群聊均可），多个用英文逗号分隔 |
| `stop_keywords` | `关闭匿名模式,结束倾诉` | 关闭会话的关键词 |
| `relay_format` | `【{name}】：{content}` | **转述格式模板**。占位符：`{name}` 匿名昵称、`{content}` 倾诉内容、`{time}` 时间（MM-DD HH:MM）；留空则用旧格式（前缀+昵称+时间一行，内容在下方） |
| `nicknames` | 水果昵称池 | **随机昵称池**。新用户开启匿名模式时随机抽取一个（同一用户固定不变）；留空则用编号兜底（如 `匿名者-001`） |
| `anon_name_prefix` | `匿名者` | 编号兜底昵称前缀（昵称池为空时生效） |
| `target_group_ids` | （空） | **必填（兜底）**。统一转述目标：私聊未命中用户规则/自动识别时使用，群聊模式未匹配规则时也使用。多群用英文逗号分隔 |
| `user_target_rules` | （空） | **私聊用户映射规则**（优先）：`用户ID:目标群1,目标群2;用户ID2:目标群3`，命中规则的用户私聊倾诉时转述到指定群 |
| `auto_detect_groups` | `true` | **自动识别倾诉者所在群**（私聊）：用户属于 A 群就转述到 A 群，同时在 A、B 群就同时转述到 A、B 群。仅 OneBot/QQ（aiocqhttp）支持，其他平台自动回退统一目标 |
| `detect_group_ids` | （空） | 自动识别的**候选群**（逗号分隔），只在这些群里查询用户；留空 = 机器人所在的全部群 |
| `group_target_rules` | （空） | **群聊映射规则**（群内开启时生效）。格式 `源群号:目标群1,目标群2;源群号2:`（分号或换行分隔多个规则）。目标留空 = 转述回来源群本身；未配置规则的群走 `target_group_ids` 统一转述 |
| `relay_prefix` | `【匿名倾诉】` | 旧格式前缀（`relay_format` 留空时生效） |
| `relay_suffix` | （空） | 旧格式后缀 |
| `show_time` | `true` | 提供 `{time}` 占位符 / 旧格式附带时间 |
| `ack_on_relay` | `true` | 转述成功后回执。群聊会话优先发私聊悄悄话，私聊不可达时改在群内提示 |
| `silent_when_off` | `true` | 私聊未开启匿名模式时保持沉默；设为 `false` 则放行给其他处理器/LLM |
| `private_whitelist` | （空） | **私聊白名单**：逗号分隔的用户 ID（如 QQ 号）。白名单内用户私聊不会被拦截、可与机器人正常对话（LLM 可回复），同时仍可开启匿名模式；支持 `平台:ID` 格式精确匹配（如 `qq:2226175932`） |
| `auto_anon_private` | `true` | **私聊自动开启匿名模式**：白名单外的人私聊机器人直接自动进入匿名模式（无需关键词）；白名单内的人不受影响，可自由聊天，需要匿名时仍发送开启关键词 |
| `enable_group_mode` | `true` | 允许群聊内开启匿名模式；关闭后群聊消息完全不干预 |
| `notify_group_on_start` | `false` | 有人开启匿名模式时在目标群内播报一条提示 |
| `max_msg_len` | `500` | 单条转述最大字数，超长自动分段发送（每段套用格式模板） |
| `session_timeout_min` | `0` | 会话空闲超时（分钟），`0` 表示不超时 |
| `admin_commands_enabled` | `true` | 启用管理命令（禁言/解禁/永久禁用/解除禁用），关闭后命令不生效 |
| `mute_default_min` | `30` | 「禁言 昵称」不带时长时的默认分钟数 |
| `censor_enabled` | `true` | 脏话自动和谐开关 |
| `bad_words` | 内置脏话列表 | 和谐词库（逗号分隔），命中即替换 |
| `censor_mask` | `**` | 和谐替换符号 |
| `review_enabled` | `true` | 内容审查开关：命中敏感词直接拦截不转述 |
| `review_words` | （空） | **审查词库**（逗号分隔）：反动、极端言论等敏感词，命中即拦截 |

## 使用流程

**私聊（默认自动匿名模式）**：

```
白名单外的用户私聊机器人：
  💬 最近工作压力好大，感觉快撑不住了……   ← 无需关键词，自动进入匿名模式
  🤖 🔇 匿名模式已开启，你的匿名身份是「番茄」… 📮 本次将转述到：816111082
  💬 感觉快撑不住了……
  🤖 已为你转述 ✅
  （群聊里显示：）【番茄】：感觉快撑不住了……

  💬 关闭匿名模式   ← 想结束随时说
  🤖 匿名模式已关闭。感谢你的信任，随时可以再来倾诉 🌱
```

白名单内的用户私聊则为普通对话（LLM 正常回复），需要匿名时发送「开启匿名模式」即可。

**私聊映射（核心场景）**：A 群的人私聊倾诉 → 转述到 A 群；B 群的人 → B 群；同时在 A、B 群 → 同时转述到 A、B 群。默认开启自动识别，无需维护名单：

```
A 群成员私聊机器人：开启匿名模式
（私聊回复：）🔇 匿名模式已开启，你的匿名身份是「番茄」…
A 群成员私聊：最近压力好大……
（群 A 里显示：）【番茄】：最近压力好大……
```

**群聊模式**（在群里直接开启匿名模式）：

```
在群 A 里发送：开启匿名模式
（机器人私聊悄悄话：）🔇 匿名模式已开启，你的匿名身份是「草莓」…
在群 A 里发送：我失恋了……
（群 A 里显示：）【草莓】：我失恋了……
（私聊悄悄话：）已为你转述 ✅
```

**映射规则示例**：

| 需求 | 配置 |
| --- | --- |
| A 群的人私聊 → A 群（自动） | `auto_detect_groups=true`，`detect_group_ids=群A号`（或留空=全部群） |
| A 群的人私聊 → B 群（手动指定） | `user_target_rules=成员A,成员B:群B号` |
| 某个用户同时转述到 A、B 群 | `user_target_rules=用户ID:群A号,群B号` |
| 所有人统一转述到 A、B 群 | 关闭自动识别或让其落空，`target_group_ids=群A号,群B号` |
| 群内开启：A 群转述回 A 群 | `group_target_rules=群A号:` |

转述目标解析顺序：**用户映射规则 → 自动识别所在群 → 统一目标（target_group_ids）**。

私聊未开启匿名模式时的私聊消息会被静默拦截（默认），机器人不会会话；群聊未开启匿名模式时完全不干预群聊。

## 管理命令（管理员专属）

管理员（AstrBot 设置中的管理员 ID）在私聊或群聊中发送以下命令，即可管理匿名身份：

| 命令 | 效果 |
| --- | --- |
| `禁言 昵称 [分钟]` | 禁言该匿名身份，时长可省略（默认 `mute_default_min` 分钟）。禁言期间其消息不会转述 |
| `解禁 昵称` | 解除禁言 |
| `永久禁用 昵称` | 永久禁用该匿名身份，其无法再开启匿名模式 |
| `解除禁用 昵称` | 恢复该匿名身份的匿名模式使用权限 |

示例：`禁言 番茄 60`（禁言「番茄」1 小时）、`永久禁用 草莓`。
禁言/禁用按匿名昵称生效（管理名单永久保存，重启不丢）。

## 脏话自动和谐

转述内容命中「和谐词库」（`bad_words`，默认内置常见脏话，可自行增删）时，会自动替换为
`censor_mask`（默认 `**`）。例如「我操你妈」会转述为「我**」。

## 内容审查（敏感词拦截）

转述内容命中「审查词库」（`review_words`，请填写反动言论、极端言论等需要拦截的敏感词，
逗号分隔）时，**整条消息直接拦截、不转述到群聊**，并告知倾诉者
「该内容未通过审查（包含敏感词），未转述」。

与「脏话自动和谐」的区别：和谐 = 替换为 `**` 后照常转述；审查 = 直接拦截不发送。
审查开关为 `review_enabled`（默认开启，词库默认留空，填了才生效）。

## 词库文件上传（txt 批量导入）

三种词库都支持用 txt 文件批量导入，有两种方式：

**方式一：插件设置页上传（推荐）**

WebUI → 插件管理 → 本插件 → 配置，找到「和谐词库文件 / 审查词库文件 / 昵称池文件」三个字段，
点击上传 txt 文件后**保存配置**（保存后插件自动重载生效）。文件会保存到插件数据目录，可随时删除或重新上传。

**方式二：聊天中直接发文件给机器人**

管理员可以直接发送 txt 文件来批量更新词库：

| 词库 | 文件名（任选其一） | 文本命令 |
| --- | --- | --- |
| 和谐词库 `bad_words` | `bad_words.txt` / `badwords.txt` / `和谐词库.txt` | 「上传和谐词库」+ 附件 |
| 审查词库 `review_words` | `review_words.txt` / `reviewwords.txt` / `审查词库.txt` / `敏感词.txt` | 「上传审查词库」+ 附件 |
| 昵称池 `nicknames` | `nicknames.txt` / `昵称池.txt` | 「上传昵称池」+ 附件 |

**通用规则**：

- **文件格式**：txt 文本，每行一个词；`#` 开头的行是注释，会被忽略；一行内也可用逗号、顿号、分号分隔多个词。
- **编码**：支持 UTF-8（含 BOM）与 GBK/GB18030（Windows 记事本「另存为 → ANSI」即可）。
- **优先级**：聊天上传的词库 > 设置页上传的文件 > 配置面板中的文本词库（缺失时自动回退到下一级）。
- **权限**：聊天上传仅管理员可用；非管理员发送的文件会被拒绝。
- **重置**：发送「重置词库」清除聊天上传的词库（恢复为设置页文件/面板配置）；也可单独发送「重置和谐词库」/「重置审查词库」/「重置昵称池」。
- **限制**：聊天上传单文件不超过 2MB、单次最多导入 10000 个词（超出部分忽略）；设置页上传上限由 AstrBot 控制。

示例：把整理好的脏话列表保存为 `bad_words.txt`（每行一个词），在私聊或群聊中直接发送给机器人即可，
回复会提示「已上传「和谐词库」：共加载 N 个词」。文件名无法识别时，也可以发「上传审查词库」并附带任意 txt 文件。

## 数据与隐私

- 插件只保存**会话状态**（用户平台标识 → 匿名编号、时间），**不保存聊天内容**。
- 数据存放在 AstrBot 的插件 KV 存储中（桌面版位于 `C:\Users\<用户名>\.astrbot\`）。
- 群内永远只出现匿名编号，不会出现真实昵称、QQ 号等身份信息。

## 常见问题

**私聊发消息没有反应？**
这是默认设计（`silent_when_off = true`）：不开启匿名模式就不会话。如需放行，把
`silent_when_off` 设为 `false`。

**群号填什么格式？**
QQ / OneBot 填群号数字即可；Telegram 填群聊 chat id（可能为负数）；多群用英文逗号分隔，如 `123456789,987654321`。

**语音、表情、视频能转述吗？**
不能，仅支持文字和图片（视频消息暂不支持）。遇到这类消息机器人会提示一次，同一会话内不再重复提示。

**转述失败？**
检查：目标群号是否正确、机器人是否在该群里、插件是否已重载、AstrBot 日志中是否有
`转述到群 ... 失败` 或 `未找到平台 ...` 报错。

**匿名编号会重复吗？**
昵称/编号全局持久化，不会重复。同一用户多次开启匿名模式昵称保持不变；如需重置，删除插件存储数据即可（WebUI 插件管理 → 数据管理）。

**词库 txt 文件的格式？**
每行一个词，`#` 开头为注释行，一行内也可用逗号/顿号分隔；支持 UTF-8、GBK 编码。可以在插件设置页上传（保存后生效），也可以聊天中发文件给机器人（仅管理员），详见「词库文件上传」章节。

**旧版本 AstrBot 能用吗？**
本插件基于 AstrBot v4 Star API（`>= 4.16`），v3 及早期 v4 不支持。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `main.py` | 插件主体：`AnonRelay(Star)` 类，实现私聊拦截、关键词开启/关闭会话、匿名转述、长文分段、词库 txt 上传、KV 持久化、主动发送到群聊 |
| `metadata.yaml` | 插件元数据：名称、显示名、简介、版本、作者、仓库地址、兼容的 AstrBot 版本范围；AstrBot 加载插件时读取 |
| `_conf_schema.json` | 插件设置面板 schema：WebUI「插件配置」的表单由此文件自动生成，每个键对应一个可编辑的配置项；词库支持 `file` 类型字段，可直接在设置页上传 txt |
| `README.md` | 本文档：安装、配置面板、使用流程、隐私说明与 FAQ |
| `LICENSE` | MIT 开源许可证，声明使用与分发条款 |
| `.gitignore` | Git 忽略规则：排除 `__pycache__` 等无关文件，保持仓库整洁 |
| `tests/test_logic.py` | 离线逻辑测试：用桩模块模拟 AstrBot API，无需安装 AstrBot 即可验证核心逻辑（`python -X utf8 tests/test_logic.py`） |

其中，AstrBot 真正运行只依赖三个文件：`main.py`、`metadata.yaml`、`_conf_schema.json`；
其余为开发与分发所需。

## 开发

- 修改 `main.py` 中的 `AnonRelayConfig` 默认值时，请同步更新 `_conf_schema.json` 的对应 `default`。
- 运行 `python -X utf8 tests/test_logic.py` 进行离线回归测试。
